# 三子棋 Three in a Row

给小朋友和大人一起玩的三子棋。规则像五子棋：两人轮流下，谁先把三个棋子连成一条线（横、竖、斜都行）就赢。

**在这里玩：https://machuiwen.github.io/three-in-a-row/**

手机、iPad、电脑都能玩。

## 怎么玩

1. 每人选一个身份（溪溪 / 爸爸 / 妈妈 / 外婆）和一个小动物当棋子。
2. 选棋盘大小：3×3、4×4 或 5×5。
3. 选谁先下，点「开始玩」。
4. 轮流点空格子下棋，先连成三个的人赢一颗星星。
5. 每局结束有「复盘」：🦉 猫头鹰老师一步一步讲为什么赢（或者为什么平局），在棋盘上点亮要看的棋子和空格，并读出来。
   - 数一数连成线的三个棋子
   - 赢之前哪里差一个，本来可以在哪里堵住；或者赢的人同时准备了两条路，堵不过来
   - 输的人是不是也差一点赢，或者赢的人在哪里堵住了对方
   - 最后一句小秘诀
   讲完才出现「再来一局」。

## 按钮

| 按钮 | 作用 |
| --- | --- |
| ↩️ 悔棋 | 退回上一步 |
| 💡 提示 | 亮出能赢的格子；没有的话，亮出要堵住的格子 |
| 🔄 重来 | 重新开始这一局 |
| 🐾 换人 | 回到选人页面 |
| 🔊 | 打开 / 关掉声音和语音 |

## 小细节

- 溪溪赢的时候，会随机说一句不同的夸夸话。
- 输的人下一局先下；平局就换人先下。
- 星星数按身份记在这台设备上，选人页面可以清零。
- iPhone / iPad 上声音跟着静音开关走。听不到的话，把开关拨到响铃。
- 一个 `index.html` 文件，不用构建，任何静态网页服务器都能打开。声音用 Web Audio 现场合成，语音用浏览器自带的中文朗读。
