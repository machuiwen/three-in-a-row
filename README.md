# 三子棋 Three in a Row

给小朋友和大人一起玩的三子棋。规则像五子棋：两人轮流下，谁先把三个棋子连成一条线（横、竖、斜都行）就赢。

**在这里玩：https://machuiwen.github.io/three-in-a-row/**

手机、iPad、电脑都能玩。

## 怎么玩

1. 输入小朋友的名字。名字只存在这台设备上。
2. 选和谁玩：
   - 👫 两个人玩：每人选一个身份（小朋友 / 爸爸 / 妈妈 / 外婆 / 外公 / 奶奶 / 爷爷）。
   - 🤖 和小动物玩：电脑来下。「让着我」会粗心，常常忘记堵、忘记赢；「认真下」不放水。
3. 每人选一个小动物当棋子。
4. 选棋盘大小：3×3、4×4 或 5×5。
5. 选谁先下，点「开始玩」。
6. 轮流点空格子下棋，先连成三个的人赢一颗星星。

## 小提醒（学习模式）

打开「要提醒」后，轮到小朋友时：

- 她差一个就赢：亮出那个空格和连着的两个棋子，说"再放一个就赢啦"。
- 对方差一个就赢：亮出要堵的空格和对方的两个棋子，说"小心！快堵住"。

学会以后可以在选人页面关掉。

## 复盘

每局结束，🦉 猫头鹰老师一步一步讲为什么赢（或者为什么平局），在棋盘上点亮要看的棋子和空格，并读出来：

- 数一数连成线的三个棋子
- 赢之前哪里差一个，本来可以在哪里堵住；或者赢的人同时准备了两条路，堵不过来
- 输的人是不是也差一点赢，或者赢的人在哪里堵住了对方
- 最后一句小秘诀

讲完才出现「再来一局」。

## 按钮

| 按钮 | 作用 |
| --- | --- |
| ↩️ 悔棋 | 退回上一步。和电脑玩时，连电脑的那一步一起退回 |
| 💡 提示 | 亮出能赢的格子；没有的话，亮出要堵住的格子 |
| 🔄 重来 | 重新开始这一局 |
| 🐾 换人 | 回到选人页面 |
| 🔊 | 打开 / 关掉声音和语音 |

## 放到主屏幕，没有网也能玩

iPhone / iPad：

1. 用 Safari 打开上面的网址（要有网）。
2. 点分享按钮，选「添加到主屏幕」。
3. 从主屏幕的图标打开一次。

之后没有网也能打开。有网的时候打开，会自动拿到最新版本。

## 小细节

- 小朋友赢的时候，会随机说一句不同的夸夸话。
- 输的人下一局先下；平局就换人先下。
- 星星数按身份记在这台设备上，选人页面可以清零。
- iPhone / iPad 上声音跟着静音开关走。听不到的话，把开关拨到响铃。
- 字体来自 Google Fonts。连不上的时候用系统字体，不影响打开。
- 不用构建：`index.html` 加上 `sw.js`（离线）、`manifest.webmanifest` 和两个图标，任何静态网页服务器都能打开。声音用 Web Audio 现场合成，语音用浏览器自带的中文朗读。
